# Super Memo / Simple Tools MVP

Super Memoを主力機能にした、Simple Toolsの静的MVPです。

## 起動
`index.html` をブラウザで開きます。

## サンプルデータ
`sample-super-memo-data.json` を用意しています。

Super Memo画面の「インポート」を押すか、JSONファイルを退避エリアへドラッグ&ドロップすると、125件の会議/アイデア/ブランクのサンプルノートと内部リンク付きの簡易グラフを確認できます。

## D3 Force Graph Demo
`force-graph-demo.html` は、D3.js v7 CDNを使ったフルスクリーンのforce-directed graph試作です。

筋トレと栄養学のダミーデータを使い、カテゴリ色分け、リンク数に応じたノードサイズ、ホバー時の1親等ハイライト、ズーム/パン、ドラッグ固定、ダブルクリック固定解除を確認できます。ドラッグ中は対象ノードの周囲を押し出すforceを追加し、他ノードが滑らかによけながら再配置されるようにしています。添付動画のObsidian風グラフに寄せて、暗いグレー背景、小さな発光ノード、細いリンク、クリックでのフォーカス固定、ズーム率に応じたラベル表示に調整しています。

## 公開向け説明
Super Memoは、フォルダ分類ではなくリンクとプロパティで知識を育てる高速メモです。

タイムスタンプID、Meeting/Ideaテンプレート、people/topics/tags、内部リンク、簡易グラフビューを使って、会議メモとアイデアメモを同じ知識グラフに積み上げます。ログインなし、外部APIなし、ブラウザ内保存だけで動きます。

Prompt Pad、メモ整形、ポモドーロ、世界時計、サブスク管理、ブックマーク、動画検索は、Super Memoへ入れる前後の文章作業、集中時間、海外とのやり取り、固定費の見直し、よく使うページへの移動、動画候補の確認を支えるサブツールとして残しています。

## データ保存
保存した内容は、利用中のブラウザの `localStorage` に保存されます。外部サーバーへの送信、クラウド同期、アカウント機能はありません。ブラウザのデータを削除すると、保存した内容も削除されます。

## 含めないもの
- ログイン
- クラウド同期
- AI API連携
- 課金
- デスクトップアプリ化
- ブラウザ内部ブックマークへの自動アクセス
